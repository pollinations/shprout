The agent stays small.

The default agent is the repository’s Bash script, byte for byte. The terminal, filesystem, authentication bridge and Linux boot code are its environment. They do not implement the agent loop.

GNU Bash inside the browser

CheerpX executes native x86 Linux programs through WebAssembly. A Debian disk image supplies Bash, Python and ordinary command-line programs. Modified disk blocks live in IndexedDB in this browser. No Bash process runs on the web server or your host operating system.

The bundled native jq 1.8.2 binary fills a missing tool in the base image. A small curl adapter transports only Pollinations chat requests through the browser. It does not offer general network access and is not a complete curl replacement. Your real API key remains outside the guest. The current device filesystem lacks /dev/fd, so process substitution such as cat <(echo hi) fails; use a pipe or a temporary file. Linux emulation has compatibility limits; a full GNU Bash executable is not a guarantee that every Linux program will work.

Lightweight alternative

just-bash executes the same agent using a JavaScript shell implementation and virtual files. It supports the agent’s required commands but cannot execute arbitrary native programs. Its command output is delivered after execution completes; the Linux terminal delivers real console output.

Optional compression

The source is already the agent’s self-description. Generating it from a compressed prompt is an optional preceding model call. Generated candidates pass scripted checks before replacing the source; those checks do not guarantee success on every task.

Hosting

Serve shell.html over HTTPS (or localhost) with Cross-Origin-Opener-Policy: same-origin and Cross-Origin-Embedder-Policy: require-corp. The development server does this. A static deployment must supply these headers. This prototype loads CheerpX 1.2.8 and a Debian disk from Leaning Technologies; check its runtime license for your deployment. It is not a self-contained offline distribution.
